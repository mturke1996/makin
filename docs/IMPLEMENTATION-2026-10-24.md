- **ملف العامل:** بحث وفلاتر للحساب والعمل والأرشيف، اتفاق ببنود أو مبلغ مقطوع، سجل نسخ الاتفاق مع السبب والمسجّل، وحماية تعديل قديم من استبدال تعديل زميل. إكمال العمل منفصل عن السداد.

- **سلامة البيانات:** رفض مبالغ المصروف غير الصالحة وربط العامل بعميل آخر. إدارة العمال مطلوبة لتغيير دفعاتهم. إصدار فاتورة المصروفات وإغلاق مصادرها، أو حذفها وإعادة فتح المصادر، يتم بمعاملة واحدة مع التحقق من تعارض التعديل.

## المكتبات والتحقق

جرى تحديث Firebase إلى 12.19، والتوجيه إلى React Router 7، والتحقق إلى Zod 4 مع resolver متوافق، وVite إلى 7.3، وPWA/Workbox، وMUI 7، وReact PDF وReact Hook Form. استُخدمت نسخة SheetJS 0.20.3 من [المصدر الرسمي](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/). بقي React 18 وTailwind 3 وZustand 4 لتجنب ترحيل واجهات لا يلزم لهذا الإصدار. ملف القفل هو مرجع الإصدارات الدقيقة.

يحتاج التطوير Node 22.12 أو أحدث ضمن 22، أو Node 24؛ اختبارات Firebase تحتاج Java 21. يوجد مسار CI للبناء والاختبارات على Windows وLinux، وفحص القواعد على Linux.
